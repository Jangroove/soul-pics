# Soul Pics v1.0.0 ユーザーガイド

Soul Picsは、背景・被写体・テキストを独立したレイヤーとして配置し、同じCanvas描画からプレビューとPNGを作るローカルWebアプリです。右上の `EN / 日本語` で表示言語を切り替えられます。

## 1. キャンバスを選ぶ

「背景」タブの「形式」から選択します。

- YouTube サムネイル・横：1280×720
- YouTube Shorts・縦：1080×1920
- Instagram 投稿・縦：1080×1440
- X プロフィールヘッダー：1500×500
- SNS プロフィールアイコン：400×400
- 自由指定：幅・高さを64〜4096pxで指定

「余白・透明部分の色」は、背景画像がキャンバス全体を覆わない部分や透過部分に使われます。

## 2. 背景を用意する

### 画像をアップロード

「背景画像をアップロード」を選んでPNG、JPEG、WebPを読み込みます。「背景の表示方法」で全面を埋める、全体を収める、引き伸ばす、素材サイズのまま、を選べます。プレビューの空いている場所をドラッグすると背景位置を動かせます。

### プロンプトから生成

背景の説明を入力して「AI背景を生成」を押します。現在のCanvas寸法とプロンプトをCodexへ渡し、生成結果をCanvas寸法に合わせて背景レイヤーに読み込みます。Codex CLIのインストールとサインインが必要です。Codexプラン利用枠を使い、Soul PicsのOpenAI APIキーは使いません。生成後の背景編集と保存はローカルです。

## 3. 被写体を切り抜く

1. 「被写体」タブで元画像をアップロードします。
2. 残したいものを日本語または英語で入力します。
3. 「ローカルで切り抜く」を押します。
4. 結果を確認し、必要なら「切り抜き素材を保存」を押します。

プロンプトの指示内容をPC内で変換し、Grounding DINO、SAM 2.1、BiRefNetで処理します。すべてローカルで行うため、別途料金は発生しません。元画像と同じ解像度・縦横比・RGBを保ち、透過アルファを生成します。初回はモデル読込に数分かかる場合があります。

「配置調整」では、サイズ、回転、X位置、Y位置、左右反転、上下反転を変更できます。被写体そのものをドラッグして移動することもできます。

## 4. テキストを追加する

「テキスト」タブで複数のテキストレイヤーを追加できます。文字、フォント、色、サイズ、位置、太字B、斜体I、下線U、縁取り、影を調整できます。さらに「テキスト背景」で、背景色、透明度、左右・上下余白、角丸、ぼかしをレイヤーごとに設定できます。プレビュー上の文字は直接ドラッグできます。

「PCフォント」は、ChromeまたはEdgeのローカルフォント権限を許可した場合に、端末へインストール済みのフォント候補を読み込みます。許可しなくても標準候補は使えます。

## 5. 画質を調整する

「画質調整」タブでは「おすすめ自動調整」の弱・標準・強を使うか、次の値を手動で調整できます。

- 色・トーン：明るさ、コントラスト、彩度、色温度
- 奥行き・輪郭：背景ぼかし、輪郭の柔らかさ、背景色の回り込み
- 質感：被写体シャープ、全体粒子
- 影：距離、濃度、ぼかし

解析と描画はすべてこのブラウザ内でローカル処理するため、別途料金は発生しません。これはCanvas 2Dによる非破壊の見た目調整であり、物理的な再照明や画像再生成ではありません。「初期状態に戻す」は画像、配置、テキストを残して画質調整値だけを戻します。

## 6. 保存する

右上の「PNGを保存」を押すと、現在のキャンバス寸法で出力します。プレビューと保存画像は同じCanvasレンダラーを使用します。背景素材と切り抜き素材は、それぞれのタブから合成前の状態でも保存できます。

## 7. AI処理の利用範囲

| 操作 | 処理場所 | 利用するもの |
|---|---|---|
| プロンプトによる被写体切り抜き | PC内のローカルAI | なし |
| Codexでの被写体切り抜き | Codex App Server | Codexプラン。ボタンを押した時だけ |
| プロンプトによる背景自動生成 | Codex App Server | Codexプラン。ボタンを押した時だけ |
| 配置、文字、画質調整、プレビュー、PNG保存 | ブラウザ内 | なし |

OpenAI APIキーの設定は不要です。Codexタスクの自動実行や自動再試行はありません。
