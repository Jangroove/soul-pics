# Soul Pics 配色・文字の視認性チェック

更新日: 2026-09-30（日本時間）\
対象: 現行v1.0.0のUI\
状態: 修正前の配色検討記録。その後v1.0.1に改善案を実装済み（[実装報告](09_UI_REFINEMENT_2026-09-30.md)参照）。以下は検討時点の比較。

## 結論

ライムグリーンのブランド色 `#21FF21` と深緑の背景は維持できる。通常のラベルや見出しは十分な明暗差があるが、仮文（placeholder）、無効ボタン、細かい操作文字に読みにくさが集中している。

今回の改善案では、読ませる文字を白寄り・明るい灰緑にし、選択状態や操作のアクセントをライム系に揃える。無効な操作は、ボタン全体の透明度を下げる方式から、専用の濃緑背景と読み取れる文字色へ変更する。

## 見つかった要因

### 1. 入力欄の仮文が暗い

現行CSSには `::placeholder` の明示色がなく、今回のChromeでは `#757575`。背景 `#030D0C` に対するコントラストは約4.27:1だった。案では `#A8BDAF` に指定し、同じ背景で約9.90:1となった。

仮文にも通常文字のコントラスト要件が適用される。目安とした通常文字4.5:1は、[W3Cのコントラスト解説](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)に基づく。

### 2. 無効ボタンの文字まで薄くなる

現行は `button:disabled { opacity: .42; filter: saturate(.4) }`、数値操作の無効ボタンは `opacity: .3`。文字、背景、枠すべてが弱くなるため、操作できない理由やボタン名を読み取りにくい。

無効なUIはWCAGの最低コントラスト要件の対象外であり、これを適合違反とは判定しない。ただし、何の操作か識別できることは重要なので、専用色で明暗差を確保する。

### 3. 選択色が緑・ミント・青緑に分散

選択タブの1番目は緑、2番目は青緑で、言語スイッチは灰緑。機能差を表す必要のない箇所でも色調が変わる。案では、選択タブと言語スイッチを淡いライム系の共通グラデーションへ揃えた。

### 4. 小さい文字による読みづらさは残る

通常ラベルの明暗差は良好でも、数値欄の約7.84〜8.4pxなど、文字の小ささと重なりによる問題がある。色だけでは解消しない。先の[画面デザイン点検](07_UI_DESIGN_REVIEW_2026-09-30.md)で提案した文字サイズ共通化と配置修正も、実装時に合わせて扱う必要がある。

## 配色案

| 役割 | 提案色 | 使い分け |
|---|---|---|
| ブランド・主要操作 | `#21FF21` | PNG保存、AI実行、ブランドアクセント |
| 操作アクセント | `#A9DA73` | 選択タブ・スライダー |
| 選択色の明るい側 | `#DCF6BD` | 選択タブ・言語スイッチのグラデーション |
| 主文字・入力値 | `#EDF5EF` | 白寄りで読ませる文字 |
| ラベル・通常説明 | `#D4E4D8` | 明るい灰緑 |
| 補足説明・非選択言語 | `#B6CBBD` | 少し落ち着いた灰緑 |
| 入力欄の仮文 | `#A8BDAF` | 未入力状態を示しつつ読み取れる明度 |
| 無効ボタンの文字 | `#AAC3B0` | 有効な文字より控えめだが読める色 |
| 無効ボタンの背景 | `#183127` | 明るい主要ボタンと区別する濃緑 |
| 課金注意文 | `#FFDB94` | アンバーで注意情報を区別 |

通常の文章をすべてライムにすると、操作の強調色と区別しにくくなるため、ブランド色は主要操作と状態表示に集中させる。見出しのネオン状文字影も外し、文字の輪郭を明瞭にした。

## 測定結果

日本語1366×768の代表値。背景色は実ブラウザの画像から採取し、文字色はCSSから取得した。透明度・saturateを含む無効状態は合成後の概算。

| 対象 | 現行 | 改善案 |
|---|---:|---:|
| 背景プロンプトの仮文 | 4.27:1 | 9.90:1 |
| 無効な背景保存ボタン | 約3.12:1 | 7.39:1 |
| 下限の無効マイナス | 約2.38:1 | 7.39:1 |
| 通常のフォントラベル | 9.90:1 | 13.49:1 |
| 位置の数値 | 11.16:1 | 16.59:1 |
| 補足キャッチコピー | 6.68:1 | 8.84:1 |
| 非選択言語ボタン | 6.19:1 | 11.43:1 |
| 選択タブ | 13.82:1 | 12.90:1 |

選択タブは色相をライムへ揃えたため比率が少し下がるが、暗い文字との十分な明暗差を保持している。

## 確認範囲と限界

日本語・英語、1366×768と375×812、現行と提案色の8組について、初期画面・画質調整・被写体の計24画像を保存。AI操作は行わず、API healthは固定応答で確認した。文字サイズとレイアウトは現行のまま比較している。

コントラスト数値は代表位置の背景を採取したもので、グラデーションの全域・全状態の最悪値や、アプリ全体のWCAG適合を保証するものではない。無効状態の値は参考値として扱う。入力枠の境界は別途調整余地があり、現行の `#315049` 対 `#030D0C` は約2.23:1。[W3Cの非テキストコントラスト解説](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)も参照し、実装時には操作を識別する枠・フォーカス表示を合わせて確認する。
